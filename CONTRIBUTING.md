# Contributing

Thank you for your interest in contributing to this project!

All contributions, bug reports, bug fixes, documentation improvements,
enhancements, and ideas are welcome.

## How to Contribute

1. **Fork** the repository to your own GitHub account.
2. **Clone** your fork locally:
   ```bash
   git clone https://github.com/your-username/simple-interest-calculator.git
   ```
3. **Create a branch** for your change:
   ```bash
   git checkout -b my-feature
   ```
4. **Make your changes**, following the existing style of the project.
5. **Test your changes** to make sure the calculator still works as expected.
6. **Commit** your changes with a clear message:
   ```bash
   git commit -m "Add: short description of change"
   ```
7. **Push** to your fork:
   ```bash
   git push origin my-feature
   ```
8. **Open a Pull Request** against the main branch of this repository,
   describing what you changed and why.

## Reporting Bugs

If you find a bug, please open an issue and include:

- A clear description of the problem
- Steps to reproduce it
- What you expected to happen vs. what actually happened

## Suggesting Enhancements

Have an idea for improving the calculator? Open an issue describing:

- What the enhancement is
- Why it would be useful
- Any examples or references, if relevant

## Documentation Improvements

Fixes or clarifications to the README or other docs are just as valuable as
code changes — feel free to submit these as pull requests too.

## Code of Conduct

By participating in this project, you agree to abide by the
[Code of Conduct](CODE_OF_CONDUCT.md).

We appreciate every contribution, big or small. Thank you for helping
improve this project!
